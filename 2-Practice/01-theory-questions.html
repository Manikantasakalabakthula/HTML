Theory Questions

1. HTML Fundamentals + Document Structure

Q1. What is HTML? Explain tags, elements, attributes, nesting, parent/child elements, void elements, and comments with simple examples.

  • HTML: HyperText Markup Language; the standard code used to structure web pages and their content.
  • Tags: Syntax keywords surrounded by angle brackets that define where an element begins and ends.
    Example: <p> (opening) and </p> (closing)
  • Elements: The complete unit from the opening tag to the closing tag, including content.
    Example: <h1>Hello World</h1>
  • Attributes: Modifiers that provide additional information or configuration inside an opening tag.
    Example: <a href="https://example.com">Visit Site</a>
  • Nesting: Placing one HTML element inside another to build hierarchy.
    Example: <p>This is <strong>important</strong>.</p>
  • Parent/Child: The outer container is the parent, and any nested element inside it is the child.
    Example: In <ul><li>Item</li></ul>, <ul> is parent, <li> is child.
  • Void Elements: Elements that close themselves and cannot hold child elements or text.
    Example: <img src="pic.jpg" alt="Photo">, <br>, <hr>, <input type="text">
  • Comments: Notes in the source code ignored by browsers during rendering.
    Example: <!-- Navigation bar starts here -->

Q2. Explain the basic structure of an HTML document. Describe <!DOCTYPE html>, <html>, <head>, <body>, lang, <title>, character encoding, viewport, and favicon.

  • <!DOCTYPE html>: Informs the browser to render the page in modern HTML5 standards mode.
    Example: <!DOCTYPE html>
  • <html>: The root element that encapsulates all other document tags.
    Example: <html lang="en">...</html>
  • lang: Specifies the primary human language of the page content.
    Example: <html lang="en">
  • <head>: Container for machine-readable metadata, styles, and links not rendered in the main view.
    Example: <head>...</head>
  • <body>: Container for all user-visible page content (text, media, layout).
    Example: <body><p>Welcome</p></body>
  • <title>: Defines the webpage name displayed in the browser tab and search results.
    Example: <title>Dashboard</title>
  • Character Encoding: Enforces standard UTF-8 character rendering for global text and symbols.
    Example: <meta charset="UTF-8">
  • Viewport: Controls layout scaling on mobile devices to ensure responsive sizing.
    Example: <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Favicon: The small brand icon shown beside the page title on the browser tab.
    Example: <link rel="icon" href="favicon.ico">

2. Text & Content

Q3. Explain headings, paragraphs, strong, em, mark, small, br, and hr with examples.

  • Headings: Six levels of sectional titles ranging from most to least important (<h1> to <h6>).
    Example: <h1>Main Title</h1>
  • Paragraphs: Represents standard blocks of text.
    Example: <p>This is a standard text block.</p>
  • strong: Indicates urgent or high-importance content; rendered bold by default.
    Example: <strong>Danger:</strong> High voltage!
  • em: Applies vocal stress emphasis; rendered italic by default.
    Example: I <em>really</em> enjoyed that.
  • mark: Highlights text for reference relevance; defaults to a yellow highlight.
    Example: Search term: <mark>HTML5</mark>
  • small: Represents secondary fine print, legal terms, or disclaimers.
    Example: <small>© 2026 Company Inc.</small>
  • br: Forces a manual line break inside inline text.
    Example: 100 Broadway<br>New York, NY
  • hr: Inserts a thematic horizontal rule to divide sections.
    Example: <hr>

Q4. Explain blockquote, q, pre, and code. When would you use each one?

  • blockquote: Used for long, multi-line quotations from external sources; renders with left indentation.
    Example: <blockquote cite="https://site.com">Long quotation...</blockquote>
  • q: Used for short, inline quotes inside a paragraph; auto-inserts quotation marks.
    Example: He replied, <q>The task is complete.</q>
  • pre: Preserves exact spaces, tabs, and line breaks in a monospace font.
    Example: <pre>Item Qty<br>Apples 5</pre>
  • code: Used to display inline code keywords, commands, or variable names.
    Example: Use the <code>map()</code> method.
  • Multi-Line Code Block: Nesting <code> inside <pre> formats programming code blocks with preserved whitespace.
    Example: <pre><code>const x = 10;</code></pre>

3. Links & Navigation

Q5. Explain the <a> element and the difference between absolute URLs, relative URLs, internal links, and fragment links with examples.

  • <a> Element: The anchor tag creates hyperlinks to other pages, files, or anchors using href.
    Example: <a href="https://example.com">Link</a>
  • Absolute URLs: Full web addresses including protocol and domain name.
    Example: <a href="https://www.google.com">Google</a>
  • Relative URLs: Paths resolved relative to the current file location.
    Example: <a href="about.html">About Us</a>
  • Internal Links: Links between different pages hosted within the same website.
    Example: <a href="/contact">Contact</a>
  • Fragment Links: In-page bookmark links targeting specific elements via their id.
    Example: <a href="#reviews">Read Reviews</a>

Q6. Explain email links, telephone links, target, rel, <nav>, and meaningful link text with examples.

  • Email Links: Uses the mailto: scheme to open default email software.
    Example: <a href="mailto:team@example.com">Email Us</a>
  • Telephone Links: Uses the tel: scheme to initiate phone calls on mobile devices.
    Example: <a href="tel:+1234567890">Call +1234567890</a>
  • target: Specifies where to display the linked resource (e.g., in a new tab).
    Example: <a href="https://site.com" target="_blank">Open Tab</a>
  • rel: Secures new-tab links by preventing tab hijacking and referrer leaks.
    Example: <a href="https://site.com" target="_blank" rel="noopener noreferrer">Secure Link</a>
  • <nav>: Semantic element that marks up main site navigation menus.
    Example: <nav><a href="/">Home</a> <a href="/shop">Shop</a></nav>
  • Meaningful Link Text: Clear, descriptive anchor text that explains destination context.
    Example: <a href="guide.pdf">Download Setup Guide</a> (instead of "Click here")

4. HTML Entities

Q7. What are HTML entities? Why are they used? Explain common entities such as &lt;, &gt;, &amp;, &quot;, and &nbsp;.

  • HTML Entities: Formatted strings starting with & and ending with ; that represent characters.
  • Why Used: To display reserved syntax characters safely without breaking HTML parsing, and to output non-keyboard symbols.
  • &lt;: Less-than operator (<).
    Example: <p>3 &lt; 8</p>
  • &gt;: Greater-than operator (>).
    Example: <p>8 &gt; 3</p>
  • &amp;: Ampersand symbol (&).
    Example: <p>Ben &amp; Jerry</p>
  • &quot;: Double quotation mark (").
    Example: <p>&quot;Hello&quot;</p>
  • &nbsp;: Non-breaking space preventing line-wrap between adjacent words.
    Example: <p>Page&nbsp;1</p>

Q8. How would you display special characters such as copyright, trademark, less-than, greater-than, and quotation marks in HTML? Give examples.

  • Copyright (©): &copy;
    Example: <p>&copy; 2026 Acme Corp.</p>
  • Registered Trademark (®): &reg;
    Example: <p>Nike&reg;</p>
  • Trademark (™): &trade;
    Example: <p>Innovate&trade;</p>
  • Less-than (<): &lt;
    Example: <p>A &lt; B</p>
  • Greater-than (>): &gt;
    Example: <p>B &gt; A</p>
  • Quotation Marks ("): &quot;
    Example: <p>&quot;Success&quot;</p>

5. Images

Q9. Explain how to add an image using <img>. Explain src, alt, width, and height. Why is alt important?

  • <img> Element: Embeds graphics and photos onto a web page.
    Example: <img src="lake.jpg" alt="Mountain lake at sunrise" width="600" height="400">
  • src: Defines the file path or URL of the image.
    Example: src="assets/logo.png"
  • alt: Provides descriptive text fallback for accessibility and failed loads.
    Example: alt="Company Logo"
  • width & height: Reserves fixed layout space to prevent page layout jumps during load.
    Example: width="300" height="200"
  • Importance of alt: Critical for screen readers used by visually impaired users, displays when network failures occur, and improves SEO.

Q10. Explain <figure>, <figcaption>, <picture>, and srcset. How can HTML provide different images for different screen sizes?

  • <figure> & <figcaption>: <figure> wraps standalone media, and <figcaption> provides its visible caption.
    Example: <figure><img src="graph.png" alt="Sales"><figcaption>Fig 1. Sales Growth</figcaption></figure>
  • <picture>: Wrapper containing multiple <source> tags for art direction and modern format switching.
    Example: <picture><source srcset="img.webp" type="image/webp"><img src="img.jpg" alt="View"></picture>
  • srcset: Lists multiple image file sources along with width/density descriptors.
    Example: srcset="small.jpg 400w, large.jpg 800w"
  • Serving Different Image Sizes: Combining srcset with sizes allows browsers to download only the optimal file based on screen resolution.
    Example: <img src="def.jpg" srcset="sm.jpg 400w, lg.jpg 800w" sizes="(max-width: 600px) 400px, 800px" alt="Responsive">

6. Lists

Q11. Explain unordered lists and ordered lists. What is the difference between <ul> and <ol>? Give examples.

  • Unordered List (<ul>): Displays bulleted list items where order is not significant.
    Example: <ul><li>Milk</li><li>Eggs</li></ul>
  • Ordered List (<ol>): Displays numbered list items where sequential order matters.
    Example: <ol><li>First Step</li><li>Second Step</li></ol>
  • Difference: <ul> uses bullets for unordered collections; <ol> uses numbers for steps, ranks, and sequences.

Q12. Explain nested lists and description lists using <dl>, <dt>, and <dd> with examples.

  • Nested Lists: A list placed inside another list item to build hierarchical menus.
    Example: <ul><li>Fruits<ul><li>Apple</li></ul></li></ul>
  • Description List (<dl>): Container for term-description and key-value pairs.
  • Description Term (<dt>): Defines the term or label name.
  • Description Details (<dd>): Defines the detailed explanation or value for the preceding <dt>.
    Example: <dl><dt>CSS</dt><dd>Cascading Style Sheets</dd></dl>

7. Tables

Q13. Explain the basic structure of an HTML table using <table>, <tr>, <th>, and <td> with an example.

  • <table>: The main container element for structured rows and columns.
  • <tr>: Table row element that groups cells horizontally.
  • <th>: Table header cell that renders bold, centered category titles.
  • <td>: Table data cell that holds regular data content.
    Example:
    <table>
      <tr><th>Name</th><th>Role</th></tr>
      <tr><td>Sam</td><td>Engineer</td></tr>
    </table>

Q14. Explain <caption>, <thead>, <tbody>, <tfoot>, rowspan, and colspan. How do they help in creating structured tables?

  • <caption>: Title or summary placed directly above the table for accessibility.
    Example: <caption>Quarterly Sales</caption>
  • <thead>, <tbody>, <tfoot>: Group header rows, body rows, and summary footer rows for styling and print pagination.
    Example: <thead><tr><th>Total</th></tr></thead>
  • rowspan: Merges a cell vertically across multiple rows.
    Example: <td rowspan="2">Spans 2 rows</td>
  • colspan: Merges a cell horizontally across multiple columns.
    Example: <th colspan="3">Spans 3 columns</th>
  • Structural Benefits: Improves accessibility for assistive readers, allows clean CSS styling targets, and enables repeated headers during printing.

8. Forms

Q15. Explain the basic structure of an HTML form. Describe <form>, <label>, <input>, <textarea>, <select>, <option>, and <button> with examples.

  • <form>: Container for user input controls with submit destination (action) and HTTP method (GET/POST).
    Example: <form action="/login" method="post">...</form>
  • <label>: Accessible description bound to an input via for="id" to expand clickable area.
    Example: <label for="user">Username:</label>
  • <input>: Versatile input field controlled by the type attribute.
    Example: <input type="text" id="user" name="user">
  • <textarea>: Multi-line text field for longer inputs.
    Example: <textarea name="msg" rows="4"></textarea>
  • <select> & <option>: Dropdown list where <select> holds the menu and <option> contains items.
    Example: <select name="role"><option value="admin">Admin</option></select>
  • <button>: Trigger element used to submit (type="submit") or reset forms.
    Example: <button type="submit">Submit</button>

Q16. Explain common input types and form attributes such as required, placeholder, name, value, min, max, minlength, maxlength, pattern, and autocomplete. Also explain HTML form validation.

  • Input Types: text, password, email, number, checkbox, radio, date, file, submit.
    Example: <input type="password">
  • name & value: name is the field key sent to the server; value is the field content.
    Example: <input type="text" name="city" value="Paris">
  • required & placeholder: required makes entry mandatory; placeholder provides a hint inside the empty field.
    Example: <input type="email" placeholder="name@site.com" required>
  • min, max, minlength, maxlength: Enforces numeric ranges or character string limits.
    Example: <input type="number" min="1" max="10">, <input type="text" minlength="5" maxlength="20">
  • pattern & autocomplete: pattern validates via RegEx; autocomplete configures browser autofill.
    Example: <input type="text" pattern="[0-9]{4}" autocomplete="postal-code">
  • HTML Form Validation: Native browser feature that checks field values against validation constraints automatically and blocks invalid submissions.

9. Semantic HTML

Q17. What is semantic HTML? Explain <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer> with examples.

  • Semantic HTML: The practice of using HTML tags that convey clear structural meaning and context to developers, browsers, and screen readers.
  • <header>: Container for introductory titles, branding, and top navigation.
    Example: <header><h1>Site Name</h1></header>
  • <nav>: Wraps primary navigation menu links.
    Example: <nav><a href="/home">Home</a></nav>
  • <main>: Houses the primary unique content of the page (used only once per page).
    Example: <main><h2>Story</h2></main>
  • <section>: A thematic grouping of content, typically grouped under a heading.
    Example: <section><h2>Features</h2></section>
  • <article>: A standalone, self-contained piece of content suitable for reuse or sharing.
    Example: <article><h2>Blog Post</h2><p>Article text...</p></article>
  • <aside>: Secondary, tangentially related content like sidebars or author boxes.
    Example: <aside><p>Related posts...</p></aside>
  • <footer>: Concluding section containing copyright info, contact details, and site links.
    Example: <footer><p>© 2026 All Rights Reserved</p></footer>

Q18. Explain <figure>, <figcaption>, <time>, and <address>. Also explain the difference between semantic and non-semantic HTML elements.

  • <figure> & <figcaption>: <figure> encapsulates standalone media, and <figcaption> supplies its visible title.
    Example: <figure><img src="pic.jpg" alt="Map"><figcaption>Office Map</figcaption></figure>
  • <time>: Encodes dates and times in machine-readable format using datetime.
    Example: <time datetime="2026-08-21">August 21, 2026</time>
  • <address>: Encloses contact details for the author or owning organization.
    Example: <address>Contact: support@example.com</address>
  • Semantic vs. Non-Semantic Elements: Semantic elements (e.g., <article>, <nav>) convey meaning to search engines and screen readers; non-semantic elements (e.g., <div>, <span>) act purely as style/script wrappers with no semantic meaning.

10. Multimedia

Q19. Explain how to add audio and video to an HTML page. Describe <audio>, <video>, <source>, and important attributes such as controls, autoplay, muted, and loop.

  • <audio> & <video>: Native HTML5 media tags for playing sound clips and video files without external plugins.
    Example: <audio src="audio.mp3" controls></audio>
  • <source>: Nested tag specifying alternate file formats (e.g., WebM, MP4) so browsers pick supported formats.
    Example: <video controls><source src="clip.mp4" type="video/mp4"></video>
  • controls: Renders default browser player controls (play, pause, volume, seeker).
    Example: <video controls>...</video>
  • autoplay: Starts playback automatically on load (requires muted in modern browsers).
    Example: <video autoplay muted>...</video>
  • muted: Starts playback with audio muted by default.
    Example: <video muted controls>...</video>
  • loop: Replays media automatically from the beginning once finished.
    Example: <audio controls loop src="music.mp3"></audio>

Q20. What is <track> used for in HTML video? Explain <iframe> and its common uses with simple examples.

  • <track>: Adds timed text tracks such as subtitles, captions (CC), and chapters via WebVTT (.vtt) files.
    Example: <track src="subtitles.vtt" kind="subtitles" srclang="en" label="English">
  • <iframe> (Inline Frame): Embeds an external document or web application within the current page.
  • Common Uses: Embedding YouTube videos, Google Maps, payment widgets, and external web content.
    Example (YouTube): <iframe src="https://www.youtube.com/embed/xyz123" title="Video" width="560" height="315"></iframe>
    Example (Map): <iframe src="https://maps.google.com/maps?q=London&output=embed" title="Map" width="400" height="300"></iframe>
